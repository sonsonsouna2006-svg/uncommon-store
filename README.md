# UNCOMMON Store — Prototype

This is the first frontend prototype for the UNCOMMON streetwear store.

## Run it locally

1. Download/unzip the project.
2. Open `index.html` in your browser.

For a more reliable local server, install VS Code and use the "Live Server" extension, or run:

python -m http.server 8000

Then open http://localhost:8000

## Current stage

- Premium dark streetwear visual direction
- Responsive mobile/desktop layout
- Homepage
- Collection section
- 4 product placeholders
- Cart drawer
- Local cart persistence
- Checkout form prototype
- UNCOMMON brand-board logo crop
